# Decisiones aprobadas para fases posteriores a 4.1

Estas decisiones fueron aprobadas por el propietario durante la Fase 4.1. Se
documentan para evitar redefinir su alcance, pero **no se implementan todavía**.

1. El DNI será obligatorio durante el registro.
2. APIsPERU validará el DNI y autocompletará los nombres y apellidos disponibles.
3. Si APIsPERU no está disponible, el registro no se completará.
4. La verificación de correo será obligatoria para las cuentas nuevas.
5. Las cuentas existentes tendrán un proceso de transición para verificar su correo.
6. El primer documento descargable será una constancia PDF de compra y no una
   boleta o factura electrónica tributaria.

La serie diaria, mensual y anual basada en `pagos.pagado_en` pertenece a la
Fase 4.2. El correo y la constancia PDF pertenecen a fases posteriores.
